# SalesFinder → Claude Remote MCP

Минимальный read-only MCP-коннектор для Claude.

## Что нужно сделать, если старый Render уже работает

1. В GitHub-репозитории старого коннектора удалите/замените старые файлы на файлы из этого архива.
2. В Render **не меняйте** уже существующие переменные:
   - `SALESFINDER_EMAIL`
   - `SALESFINDER_PASSWORD`
   - `CONNECTOR_API_KEY`
3. Дождитесь автоматического Deploy.
4. Проверьте:
   `https://ВАШ-СЕРВИС.onrender.com/health`
5. Для Claude ваш MCP URL будет:
   `https://ВАШ-СЕРВИС.onrender.com/mcp/ВАШ_CONNECTOR_API_KEY`

Не публикуйте этот полный MCP URL: хвост URL является секретом доступа к вашему SalesFinder-коннектору.

## Подключение в Claude

В Claude откройте раздел настройки/кастомизации и **Connectors (Коннекторы)**, выберите добавление пользовательского/custom connector и вставьте полный MCP URL:

`https://ВАШ-СЕРВИС.onrender.com/mcp/ВАШ_CONNECTOR_API_KEY`

OAuth Client ID / Secret оставьте пустыми: этот личный MVP защищён секретным URL.

После добавления включите SalesFinder connector в нужном чате через меню инструментов/Connectors.

## Примеры запросов Claude

- `Проанализируй WB артикул 123456789 за последние 30 дней: продажи, выручка, цена и остатки.`
- `Сравни эти три WB артикула по выручке и динамике продаж за август.`
- `Покажи поисковые запросы и позиции артикула 123456789.`
- `Найди категорию "органайзеры для кухни" на WB, создай отчёт и найди товары с выручкой от 1 млн и отзывами до 300.`

## Инструменты MCP

- `product_overview`
- `product_daily_metrics`
- `product_keywords`
- `search_categories`
- `create_category_report`
- `category_overview`
- `category_products`

Все инструменты read-only. Методы репрайсера/изменения цен намеренно отсутствуют.

## Важное ограничение SalesFinder

Коннектор сам выдерживает минимум 5.1 секунды между запросами, поскольку SalesFinder рекомендует не более одного запроса каждые 5 секунд на аккаунт.

## Безопасность

Секретный URL — упрощённая защита для личного MVP, а не полноценный OAuth. Не отправляйте полный URL другим людям и не публикуйте его. Для публичного/командного использования лучше добавить стандартную OAuth-авторизацию MCP.
